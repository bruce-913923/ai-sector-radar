# Theme Research

One file per actively researched theme.

Recommended filename:

```
{theme_id}.md
```

Each research note should preserve longitudinal evidence rather than overwrite the past with a fresh narrative.

Suggested sections:

- Current thesis
- Causal chain
- Catalysts
- Fundamental confirmation
- EPS / consensus revisions
- Contradictory evidence
- Leader / beneficiaries
- Open questions
- Change log

Scheduled jobs must read the existing note before updating it.
